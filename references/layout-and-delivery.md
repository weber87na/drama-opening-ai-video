# 版面與交付檢查

## 從需求推算幾何

先區分輸出畫布、分區、清晰有效畫面、外緣填補。這四種矩形不能混用。讓專案合成器從設定推算座標，保留每鏡裁切錨點，而不是在多個函式寫同一組像素常數。

素材寬高 `w,h`，目標清晰區 `W,H`：

- 填滿：`s = max(W/w, H/h)`，放大後裁掉超出部分。
- 全幅：`s = min(W/w, H/h)`，剩餘空間依此案補邊政策處理。
- 裁切錨點可用 `ax,ay ∈ [0,1]`：`crop_x=(scaled_w-W)*ax`、`crop_y=(scaled_h-H)*ay`。不要假設所有人臉都在中心。
- 尺寸取整後再次驗證矩形覆蓋範圍；影片像素格式如要求偶數尺寸，在設定／編碼邊界處明確處理。
- SAR 非1或含旋轉 metadata 的素材，先決定顯示座標。不能把儲存像素長寬當作顯示比例。

### 上下直接相接、只補整體上下外緣

畫布 `W×H`，`source_share` 是來源內容所占比例。來源在前時令 `q=source_share`，AI 在前時令 `q=1-source_share`；接縫 `S=round(H*q)`。上方清晰高度 `A_top≤S`，下方 `A_bottom≤H-S`：

```text
外緣填補     y = 0 .. S-A_top
上方清晰圖   y = S-A_top .. S
下方清晰圖   y = S .. S+A_bottom
外緣填補     y = S+A_bottom .. H
```

上方清晰圖的最後一列後面，直接是下方清晰圖的第一列。中間不插 pad／blur。交換順序時，同時重算兩區比例與內容，不能只改顯示標籤。

有效畫面想保留某比例 `r` 且滿寬時，高度為 `W/r`；若超過所分配區域，需調整區域、使用已允許的裁切或改補邊方案。AI 母圖依最終有效區比例設計，比事後用大量補邊更可靠。左右排列可沿 x 軸推算同樣的接觸關係；其他布局直接定義矩形和遮罩。

`outer-blur` 只描述外緣填補，不代表准許側邊模糊。若使用者選擇 contain 且要求保留全幅，與區域形狀衝突時要記錄採用的處理方式。不要偷偷改成 cover 或拉伸。

## 來源黑邊

用原始解碼畫格跨多個亮／暗場景量測，觀察黑色與灰色過渡；日夜場景暗部不能被當作黑邊。以固定或分段裁切避免抖動，保存來源尺寸、`crop_xyxy`、邊界慣例及前後對照。

裁切後仍等比例縮放。確認最靠邊的片名／台標／字幕完整，並在亮色背景檢查是否殘留細灰條。若黑邊其實只是橫向播放器容納直式影片留下的背景，說明兩者差異；不要為填滿播放器而擅自把9:16成品改成16:9。

## 按階段驗收

在大量生圖前看至少有代表性的畫風與版面。完整輸出前看複雜動態中段、最大位移及文字位置。使用者授權已明確時，以上是內部驗收，不是增加批准關卡。

### 素材／時間軸

- 所有需要的鏡頭都有素材；新增的反打、人物與情節不能由錯圖代替。
- `end_frame` exclusive，切點前一幀、切點及下一幀配對一致。來源 VFR 有明確 PTS／CFR 策略。
- 不把四捨五入秒數再轉幀，造成切點晚一幀；先確定整數影格，再導出展示用秒數。
- 所有移鏡視窗在母圖覆蓋內；每人速度與透明度各自可追溯；連續母圖銜接沒有時間換圖造成的人物跳動。
- 每項使用者要求的字層有完成記錄，來源已燒錄文字與 AI 區後製文字分開核對。

### 幾何／美術

- 有效區滿寬的設定，實際畫面不能仍有左右模糊柱。
- 外緣模糊政策生效，中間沒有意外斷帶。
- 人物比例未拉伸；重要臉、互動、道具與場景內文字不被裁掉。
- 字層不蓋住眼鼻嘴；字形清楚；移動片名和場景內文字座標系正確。
- 改構圖後重看原生字層與臉部，不以「上個版本已驗收」跳過受影響區域。

### 實際成片

- ffprobe 尺寸、FPS、影格數、音軌數與專案的目標一致；全解碼無錯。
- 時長由時間軸或既定剪輯映射得到，不固定為某支來源的長度。
- 同步對照通常只放一次原音；配音、配樂或重剪依本案設定驗證。僅在音訊應與來源相同時才以波形／相關性檢查，不能對重新配樂的成品套用原音門檻。
- 抽出真正編碼的起頭、尾端、切點前後、移鏡中段與文字極限位置。預覽PNG只證明預覽合成，不證明編碼檔正確。
- 報告寫清「全檔解碼＋多少代表畫格／動態片段抽查」，不要把抽樣稱作逐格人工驗收。

交付檔名依專案標題與版本生成；驗證通過再換成最終檔，保留前版。提供實際存在的檔案連結。短預覽、分鏡圖庫、透明素材或提示詞依當次交付需求提供，不強制每次打包全部原始影片。
