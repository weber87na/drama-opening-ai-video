# 移鏡、生成母圖與後製文字

在原片包含平移、疊影、推近、動態片名，或文字需要獨立重製時讀取。此文件提供判斷方法，不指定任何劇名、人物、台標、時間碼或畫風。

## 先辨認一段動作，再決定需要幾張圖

代表鏡頭表至少記錄：鏡頭 ID、來源起訖影格、代表影格、人物／服裝／場景、畫面層、移鏡類型、文字事件、需要的生成素材及待確認事項。代表幀用於辨識內容；鏡頭開始、中段、結尾與切點前後用於判斷動態。單張截圖不足以判定淡入或移動方向。

| 原片觀察 | 適合的重建方式 | 應核對的內容 |
|---|---|---|
| 直接換場或新增角度 | 獨立母圖與準確切點 | 人數、衣服、動作與景別是否已換；不能用上一鏡硬撐 |
| 整個畫面疊化 | 兩場景按原片時間混合 | 開始、結束與中間透明度；轉場不應偷減片長 |
| 同一長圖連續平移 | 一張固定寬幅母圖／固定空間拼接，連續移動取景窗 | 邊界內容、方向、速度、人物先後與接縫；不要逐張淡換假裝平移 |
| 斜向平移 | 同一母圖同時改變取景窗 x、y | 固定尺度時不可混入推近；畫面內容的移動方向與相機取景方向相反 |
| 兩個人物交錯移動 | 獨立透明人物層，各自軌跡與透明度，背景保持穩定 | 各自錨點、交會時刻；原片為雙重曝光時不要做成互相遮擋的實體前後景 |
| 背景不動，特寫漸現 | 固定底圖加獨立特寫透明層，僅改透明度 | 底圖不能在淡入時跟著更換、縮放或漂移 |
| 前景人物轉向後方人物特寫 | 同一深度場景母圖，連續改變裁切窗與焦點 | 起始前景人物必須存在；鏡頭推近不是突然換成另一張肖像 |
| 片名飛入、放大或移位 | 獨立透明文字／圖形層，追蹤位置、大小、透明度 | 出現、最高點、停住、退出等轉折；不要把主標當成固定角標 |

以上可組合。若原片真的有鏡頭切換，就保留切換；不要為追求一鏡到底而抹掉原有剪輯。

## 來源測量與時間座標

- 先用 ffprobe 讀取尺寸、顯示比例、時間基準、FPS、片長及音軌。保留有理數 FPS；不要把分數幀率四捨五入成整數。若為可變幀率，選擇保留 PTS 或先建立明確的固定幀率工作片，記錄時間映射。
- 以整數影格定義半開區間 `[start_frame, end_frame)`。先把來源裁段起點記錄為來源偏移，再統一推導來源時間與輸出時間。不要在多個模組分別捨入秒數，造成一格空洞或切鏡延遲。
- 在鏡頭內追蹤至少一個穩定錨點，例如眼睛、鼻尖、門框、台標外的背景特徵。以位置變化辨識平移，以特徵間距變化辨識縮放。換景與遮擋附近重新確認，不把光流錯誤當成鏡頭運動。
- 關鍵影格以來源座標或正規化座標保存，另記實際畫幅和裁切。速度、方向、停留、透明度曲線皆由該片測量或依使用者選擇設計，不沿用其他影片的數值。
- 首尾應接上相同的畫面與變換。自訂平移進場若接一般推近模組，交接兩側必須取同一時間、同一母圖與同一裁切，避免跳一下。

## 母圖尺寸與 ImageGen 提示詞

先算鏡頭整段會取到的空間，再決定母圖的長寬比與留邊。連續平移需要涵蓋整條路徑，推近需要足夠臉部細節；不要用生成後無關的第二張圖補上缺少的路徑。

先檢視使用者指定的風格影片區段或圖片，將線條、上色方式、眼睛比例、紙感、色盤、光線與背景密度寫成可替換的風格設定。若畫面有多個嵌入視窗，標示真正要參考的區域。保留原片人物的年齡感、髮型、服裝、關係與時代環境；風格變更不應增加原片沒有的現代地標或道具。

提示詞可用以下結構，每個花括號都由該案資料填寫：

```text
任務：將 {來源代表幀／參考路徑} 重建成 {指定畫風與視覺特徵}。
內容：{人物辨識特徵、表情、姿態、服裝、道具、場景與相對位置}。
取景：{鏡頭景別、目標清晰區比例、起始與結束取景範圍}。
連續性：與 {已選定角色／場景參考} 保持一致；保留 {必須完整出現的內容}。
移鏡需求：{固定母圖／寬幅平移／前後景推近／獨立透明人物層}；預留 {實際需要的空間}。
後製：此素材 {不含文字與台標／列出必須在場景內保留的實體文字區域}。
輸出：{比例與透明需求}；{對應的避免事項}。
```

透明人物、獨立特寫或去背素材要真的要求透明背景，並檢查 alpha 通道；不是畫成棋盤格。保存選定結果與每次提示詞，不把失敗版本覆蓋掉。生成工具需先看到引用的本機圖片；使用內建 ImageGen，依可用工具的實際介面傳遞參考。

一般影片裁切、相機變換、疊字及排版屬合成工作；若要補畫缺失人物、改服裝、延伸場景或移除畫中物件，回到影像生成／編輯流程，不用模糊或放大掩飾缺圖。

## 畫幅與取景

母圖的目標畫幅、黑邊裁切、cover／contain 與外緣填補推算，見 [版面與交付檢查](layout-and-delivery.md)。改動取景後，重新檢查本文的整段移鏡路徑與獨立字層。

## 文字與台標必須有獨立交付狀態

建立文字事件清單，逐項標記 `required`、內容來源、顯示區域、起訖影格、座標系、素材／字型、位置／比例／透明度關鍵幀、校對狀態及完成狀態。演員名、角色名、片名、集數、歌詞與台標分開記錄；不默認每部劇都使用相同項目或台標。

兩種座標系不能混用：

- **畫面固定（screen-space）**：角落台標、演職員與歌詞，通常在相機裁切後合成。位置相對當前顯示區，另加該區在整體畫布的位置。
- **場景附著（scene-space）**：書封文字、招牌等，先在母圖座標合成，再與書本／場景一起平移、縮放或透視變換。不能在螢幕上飄著不隨物件移動。

文字可重新排版或使用乾淨的透明圖層；需參照原片字形、描邊、顏色與行向。若從影片擷取台標／字卡，檢查殘留背景、鋸齒與髒邊。縮放帶 alpha 的素材時，使用預乘 alpha 或等效方法防止黑邊／白邊。

**來源區保留已燒錄的歌詞，不代表 AI 區的歌詞已完成。** 以使用者要求的顯示區域逐項驗收。文字遮罩抽取失敗時，改用可核對的文字轉錄、人工校正與重新排字；不能沿用某個舊專案未完成歌詞的限制當作新任務預設。若必要內容仍無法取得，明確列為未完成並處理所缺資訊，不能標記成片完整交付。

變更比例、裁切或人物大小後，重新檢查字層是否蓋到眼鼻嘴。只改有問題鏡頭的位置，並檢查該鏡整段動態，避免代表幀安全但中途撞臉。書封等場景文字還要檢查字形完整、四角不出界，以及與固定角標的重疊。

## 動態驗收

預覽要涵蓋特殊動態的開始、中間與結束，不能以一張代表圖當作移鏡完成。核對交錯人物各自的速度與錨點、透明特寫是否只改Alpha、推近母圖是否保持同一空間、字層是否在整段不遮住五官，以及交接兩側是否用同一時間和變換。

抽查實際編碼影片中的上述時刻；一般尺寸、時間軸、音訊與交付檢查見 [版面與交付檢查](layout-and-delivery.md)。使用者已授權製作時，預覽是內部品質檢查，不增加逐段批准關卡。
